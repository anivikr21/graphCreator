# graphCreator

A simple, browser-based tool for generating clean and customizable graphs using Chart.js. Enter your data, choose your colors and chart type, and instantly render a visual you can export or share.

## Features
- Supports bar and line charts  
- Custom color selection  
- Live graph rendering  
- Responsive layout  
- Zero dependencies beyond Chart.js

## How to Use
1. Open the site:  
   `https://anivikr21.github.io/graphCreator/graphCreator.html`
2. Enter your data values (comma-separated).  
3. Pick a chart type and color.  
4. Click **Build Chart** to generate the graph.
